# EV Gate

A deterministic EV viability assessment engine designed to reduce poor-fit EV purchasing decisions through restrained, plain-English logic.

## Principles

- Deterministic outcomes
- Consumer Duty-safe wording
- No persuasive sales language
- One-question-per-screen UX
- Conservative viability assessment
